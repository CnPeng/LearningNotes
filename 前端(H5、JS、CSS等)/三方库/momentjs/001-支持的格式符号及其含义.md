# 001-支持的格式符号及其含义

`moment.js` 是一个流行的 JavaScript 日期处理库，它提供了丰富的日期和时间格式化选项。使用 `format` 方法时，你可以使用各种自定义格式字符串来格式化日期和时间。以下是一些常用的格式符号及其含义：

- `YYYY`: 四位数的年份，如 `2023`
- `YY`: 两位数的年份，如 `23`
- `MM`: 两位数的月份（01-12）
- `M`: 月份（1-12，不补零）
- `DD`: 两位数的日期（01-31）
- `D`: 日期（1-31，不补零）
- `HH`: 24小时制的小时（00-23）
- `H`: 24小时制的小时（0-23，不补零）
- `hh`: 12小时制的小时（01-12）
- `h`: 12小时制的小时（1-12，不补零）
- `mm`: 分钟（00-59）
- `m`: 分钟（0-59，不补零）
- `ss`: 秒（00-59）
- `s`: 秒（0-59，不补零）
- `SSS`: 毫秒（000-999）
- `A`: AM/PM标记（上午/下午），大写
- `a`: am/pm标记（上午/下午），小写
- `ddd`: 三位缩写的星期名称（如 Sun, Mon）
- `dddd`: 完整的星期名称（如 Sunday, Monday）
- `Do`: 带有英文序数词的日期（如 1st, 2nd）
- `Mo`: 带有本地化序数词的日期（取决于语言设置）

一些示例格式化字符串及其输出：

- `'YYYY-MM-DD HH:mm:ss'`：`2023-05-11 15:30:00`
- `'ddd MMM D YYYY'`：`Thu May 11 2023`
- `'h:mm a'`：`3:30 PM`
- `'MMMM Do YYYY, h:mm:ss a'`：`May 11th 2023, 3:30:00 pm`

你还可以在格式化字符串中插入非日期时间的文本，只需用 `[` 和 `]` 包围文本，例如：`'YYYY[年]MM[月]DD[日]'` 会输出 `2023年05月11日`。

请注意，随着时间的推移，库可能会有更新和改进，因此建议查阅最新的 `moment.js` 文档以获取最准确和最全面的格式支持信息。
