# 1. 002-样式中定义的背景图片在生产环境不显示

## 1.1. 现象

项目基于 Vite + Vue3 构建。

在 `src/asstet/photos` 目录下有一张图片，假设名称为 `bg_shichangzonglan.png`，我们在样式中将其作为背景图片来使用。在开发过程中可以正常显示，但打包部署到线上环境之后，却无法显示。

样式代码如下：

```less
.regionContainer {
  background-image: url('src/assets/photos/bg_shichangzonglan.png');
  background-size: cover; /* 使背景图覆盖整个元素 */
  background-position: center; /* 居中显示背景图 */
  background-repeat: no-repeat; /* 不重复背景图 */
  width: 100%;
  overflow-y: auto; /* 启用垂直滚动 */
}
```

然后在组件中使用该样式：

```vue
<div class="regionContainer">
    <!--其他内容省略 -->
</div>
```

## 1.2. 解决方案

以相对路径的方式通过 `url` 进行引用，这样修改后，不论是开发过程中还是部署之后，都可以正常显示。 

```less
.regionContainer {
    background-image: url('../../../assets/photos/bg_shichangzonglan.png'); /* 设置背景图 */
    /* 其他内容省略 */
}
```
