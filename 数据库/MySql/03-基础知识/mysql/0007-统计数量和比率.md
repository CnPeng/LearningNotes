# 1. 统计数量和比率

## 1.1. mysql中如何统计比率

在 MySQL 中统计比率可以使用 `COUNT` 函数和 `GROUP BY` 子句。

例如，假设我们有一个表格存储了学生的成绩信息，包括学生姓名和成绩，我们可以使用以下 SQL 语句统计及格率和不及格率：

```sql
SELECT
    CONCAT(ROUND(COUNT(CASE WHEN score >= 60 THEN 1 END) / COUNT(*) * 100, 2), '%') AS pass_rate,
    CONCAT(ROUND(COUNT(CASE WHEN score < 60 THEN 1 END) / COUNT(*) * 100, 2), '%') AS fail_rate
FROM
    scores;
```

这里使用了 `COUNT` 函数和 `CASE WHEN` 语句来统计及格和不及格的人数，然后使用 `CONCAT` 和 `ROUND` 函数将比率转换为百分数形式并保留两位小数。

注意，这里**要使用 `CONCAT` 函数将比率和百分号符号连接起来，否则会将比率按照普通数字处理并丢失百分号符号**。

## 1.2. 上一步的示例代码中， `then 1 END` 是什么意思

在上一步的示例代码中，`CASE WHEN score >= 60 THEN 1 END` 是一个条件表达式，它的含义是：

* 如果 `score >= 60`，则返回 1；
* 如果 `score < 60`，则返回 NULL（因为没有指定 ELSE 语句）。

在这个例子中，我们使用了 `COUNT` 函数来统计符合条件的记录数，因此当 `score >= 60` 时， `COUNT` 函数会将返回值1计入统计，而当 `score < 60` 时，返回值为 NULL，不会计入统计。

需要注意的是，`CASE WHEN ... THEN ...` 语句中的 `THEN` 关键字后面可以是任意表达式，不一定是1，可以根据实际情况进行修改。

## 1.3. `CASE WHEN ... THEN ...` 的使用示例

`CASE WHEN ... THEN ...` 是一个条件表达式，可以用来根据不同的条件返回不同的结果，其基本语法如下：

```sql
CASE expression
    WHEN value1 THEN result1
    WHEN value2 THEN result2
    ...
    ELSE default_result
END
```

其中， `expression` 是要比较的表达式，`value1` 、`value2` 等是要比较的值，`result1`、`result2` 等是对应的返回结果，`default_result` 是当所有条件都不满足时的默认返回结果（可以省略）。

下面是一个使用 `CASE WHEN ... THEN ...` 的示例，假设我们有一个表格存储了商品销售信息，包括商品名称和销售数量，我们想要将销售数量按照不同的范围进行分组，并统计每个范围内的销售数量。可以使用以下 SQL 语句：

```sql
SELECT
    CASE
        WHEN sales <= 100 THEN '0-100'
        WHEN sales <= 500 THEN '101-500'
        WHEN sales <= 1000 THEN '501-1000'
        ELSE '1001以上'
    END AS sales_range,
    COUNT(*) AS sales_count
FROM
    sales_info
GROUP BY
    sales_range;
```

在这个例子中，我们使用了 `CASE WHEN ... THEN ...` 语句将销售数量按照不同的范围进行分组，对于不同的销售数量范围，返回不同的范围名称，然后使用 `COUNT` 函数统计每个范围内的销售数量。最后使用 `GROUP BY` 子句将所有数据分组，按照不同的范围进行统计。

## 1.4. CASE WHEN ... THEN ...的使用限制

在使用 `CASE WHEN ... THEN ...` 语句时，需要注意以下几个限制：

* 1. `CASE WHEN ... THEN ...` 语句只能出现在 SELECT、WHERE、HAVING 和 ORDER BY等支持表达式的位置，不能用于 FROM 子句中。

* 2. `CASE WHEN ... THEN ...` 语句中的所有分支返回值的数据类型必须相同或可以隐式转换为相同的数据类型。

* 3. `CASE WHEN ... THEN ...` 语句中的分支条件必须是可比较的，即必须是相同的数据类型或可以隐式转换为相同的数据类型。

* 4. `CASE WHEN ... THEN ...` 语句中的分支条件是从上到下依次匹配的，只要有一个分支条件匹配成功，就返回对应的结果并结束。

* 5. `CASE WHEN ... THEN ...` 语句可以有 `ELSE` 分支，用于处理所有不满足前面条件的情况。

* 6. `CASE WHEN ... THEN ...` 语句可以嵌套使用，但是嵌套的层数不宜过多。

需要注意的是，`CASE WHEN ... THEN ...` 语句的使用限制可能会因不同的数据库而有所不同，具体使用时需要参考对应数据库的文档进行了解。
