# 1. 0016-存储地理坐标


## 1.1. 数据库存储经纬度信息：

### 1.1.1. 建表语句：

```sql
CREATE TABLE `coordinate_test` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `coordinate` point NOT NULL,
  `remark` varchar(45) NOT NULL DEFAULT '',
  PRIMARY KEY (`id`),
  SPATIAL KEY `index2` (`coordinate`)
) 
```

### 1.1.2. 插入数据

* 正确示例：

```sql
insert into coordinate_test (`coordinate`, `remark`) values(Point(117.136685,36.206496), '山东省泰安市泰山区泰安八十八医院');

insert into coordinate_test (`coordinate`, `remark`) values(Point(117.127922,36.211289), '山东省泰安市泰山区泰山风景区红门');

insert into coordinate_test (`coordinate`, `remark`) values(Point(117.120747,36.292839), '山东省泰安市泰山区螭霖鱼保护区');
```

* 错误示例：

```sql
-- 错误数据，经度纬度传反了
insert into coordinate_test (`coordinate`, `remark`) values(POINT(36.211289,117.127922), '山东省泰安市泰山区螭霖鱼保护区');
```


### 1.1.3. 查询

* 普通查询

```sql
SELECT * FROM coordinate_test;
-- 南天门附近
select ST_AsGeoJSON(coordinate) from coordinate_test;
```

* 查询坐标点之间的距离

```sql
select *, ST_AsGeoJSON(coordinate), ST_Distance_Sphere(coordinate, Point(117.136685,36.206496)) as distance_sphere, ST_Distance(coordinate, Point(117.136685,36.206496)) from coordinate_test order by distance_sphere;

select *, ST_AsGeoJSON(coordinate), ST_Distance_Sphere(coordinate, Point(117.136685,36.206496)) as distance_sphere from coordinate_test order by distance_sphere;
```


## 1.2. 使用GORM查询坐标点之间的间距


要在 GORM 的 Raw SQL 查询中动态传入参数，你可以使用 GORM 的 `db.Raw()` 方法结合 Go 语言的字符串格式化功能。这里有一个例子说明如何将经纬度作为参数动态传入查询：

```go
package main

import (
	"fmt"
	"github.com/jinzhu/gorm"
	_ "github.com/jinzhu/gorm/dialects/mysql"
)

type Location struct {
	gorm.Model
	Coordinate gorm.Geometry `gorm:"type:point"` // 假设已定义
	// 其他字段...
}

func main() {
	db, err := gorm.Open("mysql", "user:password@/dbname?charset=utf8&parseTime=True&loc=Local")
	if err != nil {
		panic("failed to connect database")
	}
	defer db.Close()

	// 动态参数
	latitude := 36.206496
	longitude := 117.136685

	// 构建SQL字符串，使用 ? 占位符
	sql := fmt.Sprintf(`
		SELECT *, ST_AsGeoJSON(coordinate), 
		ST_Distance_Sphere(coordinate, Point(?, ?)) AS distance_sphere, 
		ST_Distance(coordinate, Point(?, ?))
		FROM locations
		ORDER BY distance_sphere;
	`, longitude, latitude, longitude, latitude)

	var results []Location
	// 使用 db.Raw() 并通过 Args 传递参数
	db.Raw(sql, longitude, latitude, longitude, latitude).Scan(&results)

	for _, loc := range results {
		// 处理结果...
	}
}
```

在这个例子中，我们使用 `fmt.Sprintf()` 函数来构造含有占位符（`?`）的 SQL 查询字符串，然后在 `db.Raw()` 调用中通过 `Args` 参数传入实际的值。这样可以确保查询参数被正确且安全地绑定，防止 SQL 注入攻击。

请确保你的数据库连接字符串、表名、字段名等与实际情况相符，并根据需要调整错误处理逻辑。

## 1.3. 问题解决

在插入数据时容易出现 `1416 - Cannot get geometry object from data you send to the GEOMETRY field` ，可参考如下两个方案进行解决。

### 1.3.1. 参考1

确认是否经纬度填写反了。构建 `Point` 时，第一个参数是经度（ longitude ），第二个参数是纬度（ latitude ）。

### 1.3.2. 参考2

[原文](https://blog.csdn.net/zzc_zcc/article/details/78836505)

mysql 中`point`、`linestring` 可用于存储空间坐标，在 `insert` 时可能会出现：`1416 - Cannot get geometry object from data you send to the GEOMETRY field` 等相关错误。这可能是 `insert` 语句写的不对，下面演示一下相关操作及对应结果。



```sql
CREATE TABLE `test` (
`id`  int(11) NULL DEFAULT NULL ,
`lstr`  linestring NULL DEFAULT NULL ,
`pt`  point NULL DEFAULT NULL
)
ENGINE=InnoDB
DEFAULT CHARACTER SET=utf8 COLLATE=utf8_croatian_ci
ROW_FORMAT=COMPACT;
```

字段 `lstr` 是 `linestring` 类型，`pt` 是 `point` 类型。

直接贴出能正确插入的 sql 语句

对于linestring类型：

```sql
insert into test(id,lstr) values (1,POINTFROMTEXT('LINESTRING(10 15)'));   ----成功

insert into test(id,lstr) values (1,GeomFromText('LINESTRING(1 -1)'));    ----成功

insert into test(id,lstr)  values (1,'LINESTRING(10 15)');  ----失败
1416 - Cannot get geometry object from data you send to the GEOMETRY field

insert into test(id,lstr)  values (1,LINESTRING('11','12'));  ----失败    
1367 - Illegal non geometric ''11'' value found during parsing

```


对于point类型：

```sql
insert into test(id,pt)  values (1,POINTFROMTEXT('POINT(10 15)'));   ----成功

insert into test(id,pt) values (1,GeomFromText('POINT(1 -1)'));    ----成功

insert into test(id,pt)  values (1,'POINT(12 13)');     ----失败
1416 - Cannot get geometry object from data you send to the GEOMETRY field

insert into test(id,pt)  values (1,POINT('10','15')); ----成功
```


这里提一下，对于阿里云的 rds 数据库，point 类型或者 linestring 类型可以通用。即在 point 字段能存 linestring 类型数据，在 linestring 字段能存 point 类型数据。

## 1.4. Go+Gorm+Mysql 实现坐标存储和距离比较

> 以下示例代码摘自 《碳小宝》 的服务端。


### 1.4.1. 坐标存储

在 MySql 数据库中，坐标点存储格式为 `POINT(经度,纬度)`，数据类型为 `POINT`.

但是在定义 go 结构体时，不论是使用 string 还是自定义类型，gorm 都无法正常转换为 `POINT` 类型，一直报错。

所以此处使用 `*any` 类型来定义 `Coordinate` 字段，在存储数据时分两步走：先存储除 `Coordinate` 以外的字段，然后以 `UPDATE` 的形式更新该字段。
 
* 字段定义：

```go
// RewardPointCheckInCfg 低碳打卡积分配置, 低碳打卡积分配置
type RewardPointCheckInCfg struct {
    Coordinate *any    `gorm:"column:coordinate;type:POINT;comment:'打卡中心点坐标。格式：POINT(经度,纬度)'"`
    // 其他字段省略
}
```

* 更新坐标（摘自：`model/reward_point_check_in_cfg.go`）

```go
// UpdateCoordinate 更新坐标点对象（由于创建的时候无法直接存储坐标对象，所以，单独定义一个更新方法）
// 初始时计划直接使用下面的 updateByMap 实现坐标更新，但实测不好使，所以单独定义了这个只更新坐标点对象的方法。
func (a *RewardPointCheckInCfgDao) UpdateCoordinate(ctx context.Context, v *schema.RewardPointCheckInCfg) error {
    db, ok := a.applyUpdateParams(ctx, v)
    if !ok {
        return errors.New("缺少必要的参数record_id")
    }

    tableName := entity.RewardPointCheckInCfg{}.TableName()
    // 这种方式必须用空格间隔经纬度
    // rawSql := fmt.Sprintf("UPDATE %s SET coordinate = ST_GeomFromText('POINT(? ?)') WHERE record_id = ?", tableName)
    // 这种方式必须使用逗号间隔经纬度
    rawSql := fmt.Sprintf("UPDATE %s SET coordinate = POINT(?,?) WHERE record_id = ?", tableName)
    db = db.Exec(rawSql, v.Longitude, v.Latitude, v.RecordId)

    if err := db.Error; err != nil {
        return err
    }
    return nil
}

// UpdateByMap  基于传入的map进行更新
func (a *RewardPointCheckInCfgDao) UpdateByMap(ctx context.Context, pMap map[string]any) error {
    // map不能为空
    if len(pMap) == 0 {
        return nil
    }

    // 判断记录ID
    recordID, ok := pMap["record_id"]
    if !ok || recordID == "" {
        return errors.New("缺少必要的参数-record_id")
    }

    db := withTransaction(ctx, a.db).Model(entity.RewardPointCheckInCfg{}).Where("record_id = ?", recordID)
    if err := db.Updates(pMap).Error; err != nil {
        return err
    }
    return nil
}
```

### 1.4.2. 坐标距离比较

在 Mysql 数据库中使用 `ST_Distance_Sphere` 函数可以计算两个坐标点之间的距离，单位：米。

下面的代码中，`range` 是数据库中的字段，表示有效打卡范围，单位：公里。（摘自：`model/reward_point_check_in_cfg.go`）

```go
// GetValidCfgs 基于传入的坐标点判断是否在有效打卡范围内,是，则返回配置。
func (a *RewardPointCheckInCfgDao) GetValidCfgs(ctx context.Context, cfgID string, longitude float64, latitude float64) (schema.RewardPointCheckInCfgs, error) {
    db := withTransaction(ctx, a.db).Model(entity.RewardPointCheckInCfg{})
    if cfgID != "" {
        db = db.Where("record_id = ?", cfgID)
    }
    db = db.Where("ST_Distance_Sphere(coordinate, Point(?, ?)) < (`range`*1000)", longitude, latitude)

    var results entity.RewardPointCheckInCfgs
    if err := db.Find(&results).Error; err != nil {
        return nil, err
    }
    return results.ToSchemaEntities(), nil
}
```
