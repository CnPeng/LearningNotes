# 1. README

基于 [B站-黑马程序员全网最全Coze智能体入门到项目实战](https://www.bilibili.com/video/BV12omoB4ExF) 整理。

点击进入 [Coze 官网](https://www.coze.cn/home)

>最近有小伙伴反馈，Coze平台进行了更新，导致不知道该如何操作设计智能体，在这里刚哥给大家声明一下，虽然Coze进行了更新，但是功能基本没发生改变，我们在选择创建智能体时，可选择两种方式可以进入和视频中教程一致的画面。
第一种方式：进入 [https://code.coze.cn/home](https://code.coze.cn/home) 官网后，点击右上角：回到旧版，即可操作
第二种方式：进入 [https://code.coze.cn/home](https://code.coze.cn/home) 官网后，点击聊天框下面的《智能体开发》即可操作
