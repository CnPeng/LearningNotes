# 1. 011-加载包含中文的路径

## 1.1. 问题

```swift
if let url = URL(string: "http://h5.xinjiewy.cn/content-system/?/home-index/6/通知消息") { 
    let request = URLRequest(url: url)
    self.webView?.load(request)
    startLoadingAnimation()
}
```

上述代码中，`webView` 是一个 `WKWebView` 对象，为什么它不会正常加载对应的页面？

## 1.2. 解决

这段代码中，你试图在 WebView 中加载一个**带有中文路径段的 URL**。

**在 HTTP 或 HTTPS 协议下，URL 中的中文以及其他非 ASCII 字符必须进行 URL 编码才能被正确识别和解析**。因此，像 "通知消息" 这样的中文字符串会导致 URL 加载失败。

为了修正这个问题，你需要将中文字符串进行 URL 编码：

```swift
let targetUrl = "http://h5.xinjiewy.cn/content-system/?/home-index/6/通知消息"
if let urlStr = targetUrl.addingPercentEncoding(withAllowedCharacters: .urlHostAllowed),let url = URL(string: urlStr) {
    let request = URLRequest(url: url)
    self.webView?.load(request)
    startLoadingAnimation()
}
```

在这段代码中，我们使用了 `addingPercentEncoding(withAllowedCharacters:)` 方法对 URL 字符串进行编码，确保它可以被正确解析。不过，对于路径部分，应当使用 `.urlPathAllowed` 而非 `.urlHostAllowed`，因为 **`.urlHostAllowed` 主要用于主机名编码**：

```swift
let targetUrl = "http://h5.xinjiewy.cn/content-system/?/home-index/6/通知消息"
if let urlStr = targetUrl.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed),let url = URL(string: urlStr) {
    let request = URLRequest(url: url)
    self.webview?.load(request)
    startLoadingAnimation()
}
```

这里使用了 **`.urlQueryAllowed`，因为它不仅包括路径允许的字符，也包括查询字符串允许的字符，适合于这种混合路径和查询字符串的场景**。**如果只有路径部分需要编码，可以改为 `.urlPathAllowed`。**

但是，请注意，对于路径内的中文，通常服务器端也需要能够正确处理编码后的 URL 才能访问到正确的资源。如果服务器端不支持编码后的路径，可能需要联系服务器管理员进行相应的适配。
