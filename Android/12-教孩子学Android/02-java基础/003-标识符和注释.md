# 1. 003-变量和常量

## 1.1. 标识符

### 1.1.1. 基本规则

用来表示包名、类名、方法名、参数名、变量名等的这些字符，就被称为 **标识符**。

标识符可以由任意的字母、数字、下划线（`_`） 和 美元符号（`$`）组成，但不能以数字开头，不能是 java 中的关键字。

> `关键字` 参考下一小节。

合法的标识符示例：

```java
userName
userName123
user_name
_userName
```

非法的标识符示例：

```java
// 错误原因：不能以数字开头
123UserName
// 错误原因：不能使用关键字作为标识符
class
// 错误原因：标识符中不能包含空格。
Hello World
```

### 1.1.2. 其他规则

> 先了解并记忆。至于包名、类名等的含义后面再介绍。

* 包名所有字母一律小写
* 类名和接口名每个单词的首字母都要大写，如 ArrayList、ClickCallBack。
* 常量名所有字母都大写，单词之间使用下划线连接，如：DAY_OF_MONTH
* 变量名和方法名第一个单词的首字母小写，从第二个单词开始每个单词首字母大写，如：userName、getUserName。（即**驼峰命名规范**。）
* 在定义标识符时尽量见名知意，如：getUserName 用于获取用户名称，changeUserName 用于变更用户名称。


## 1.2. 关键字

**关键字** 是指编程语言中预先定义好并赋予了特殊含义的单词（即 标识符），也称为 **保留字**。不能用作变量名、类名或方法名（也就是说，关键字不能做标识符）。

java 中关键字有很多，常用的有`public`、`class`、`static`、`void`、`if`、`for`、`return` 等。

> 注意：这些关键字不需要强制记忆，日常编码中如果错误使用了关键字程序会报错，根据错误提示修改即可。

### 1.2.1. 访问控制关键字

- `public` - 公开访问
- `protected` - 受保护访问
- `private` - 私有访问

### 1.2.2. 类、方法和变量修饰符

- `abstract` - 抽象类或方法
- `class` - 定义类
- `extends` - 继承
- `final` - 不可改变的
- `implements` - 实现接口
- `interface` - 定义接口
- `native` - 本地方法
- `new` - 创建对象
- `static` - 静态的
- `strictfp` - 严格浮点
- `synchronized` - 同步
- `transient` - 瞬态
- `volatile` - 易变的

### 1.2.3. 程序控制

- `if` - 条件判断
- `else` - 否则
- `switch` - 多分支选择
- `case` - 分支情况
- `default` - 默认分支
- `while` - 循环
- `do` - 循环
- `for` - 循环
- `break` - 跳出循环或switch
- `continue` - 继续下一次循环
- `return` - 返回值
- `instanceof` - 实例类型检查

### 1.2.4. 异常处理

- `try` - 尝试执行
- `catch` - 捕获异常
- `finally` - 最终执行
- `throw` - 抛出异常
- `throws` - 声明可能抛出的异常

### 1.2.5. 包相关

- `import` - 导入包
- `package` - 定义包

### 1.2.6. 基本类型

- `boolean` - 布尔型
- `byte` - 字节型
- `char` - 字符型
- `double` - 双精度浮点
- `float` - 单精度浮点
- `int` - 整型
- `long` - 长整型
- `short` - 短整型

### 1.2.7. 变量引用

- `super` - 父类引用
- `this` - 当前对象引用
- `void` - 无返回值

### 1.2.8. 保留字（特殊关键字）

- `enum` - 枚举类型（Java 5+）
- `assert` - 断言（Java 1.4+）
- `const` - 未使用（保留为关键字）
- `goto` - 未使用（保留为关键字）

### 1.2.9. Java 10+ 增加的上下文关键字

- `var` - 局部变量类型推断（Java 10+）

- `record` - 记录类（Java 14+，Java 16正式）

- `sealed` - 密封类（Java 15预览，Java 17正式）

- `non-sealed` - 非密封类

- `permits` - 允许继承

- `yield` - switch表达式返回值（Java 13预览，Java 14正式）

### 1.2.10. 注意点

- `const` 和 `goto` 在 Java 中是保留字但从未使用

- `true`、`false`、`null` 看起来像关键字，但实际上是字面量

- 从 Java 9 开始，`_`（下划线）不能单独作为标识符

- 上下文关键字只在特定上下文中是关键字


## 1.3. 注释

在编码过程中，用于描述代码含义的文本被称为 `注释`。

java 中的注释有三种：单行注释、多行注释（块注释）、文档注释。

不同的注释有不同的书写规范。合理的添加注释可以增加代码的可维护性。

### 1.3.1. 单行注释

对代码进行描述的单行文本称为单行注释，通常定义在代码上方一行。

基本格式：`// 单行注释内容`。以 `//` 开头，后面书写注释内容。

示例：

```java
// 定义一个字符串类型的变量，变量名称为 name ,变量初始值为 "张三"
String name = "张三";
```

### 1.3.2. 多行注释（块注释）

对代码进行描述的多行文本称为多行注释，也叫块注释。

基本格式：`/* 用于描述代码含义的多行文本 */`,  以 `/*` 开头，以 `*/` 结尾，中间是多行描述文本。

示例：

```java

/* 这是一个多行注释，如果内容比较多，可以直接换行。
   单行注释不支持换行。*/
String name = "李四";
```

### 1.3.3. 文档注释

文档注释是对多段代码的解释说明。通过 `javadoc` 命令可以将文档注释提取出来生成帮助文档。

基本格式：`/** 注释内容 */`, 以 `/**` 开头，以 `*/` 结尾，中间是注释内容。

示例：

```java
/**
 * 这是一个用户类.
 * 提供了两个变量 name 和 grade,
 * 提供了一个用于获取用户信息的 getUserInfo() 方法
 */
public class User {
    // 定义一个变量 name , 并使用单行注释
    String name = "张三";

    /* 定义一个 int 类型变量，用于表示年级。
       这里使用的是多行注释。*/
    int grade = 4;

    /**
     * 文档注释通常作为 类 或者 方法的注释。
     */
    public void getUserInfo() {
        String info = name + "是一名" + grade + "年级的小学生";
        System.out.println(info);
    }
}
```
