# 1. 006-运算符

在 java 语言中，运算符包括：算术运算符、赋值运算符、比较运算符、逻辑运算符、位运算符。

> 位运算符是针对二进制数的每一位进行运算的符号，它是专门针对数字 0 和 1 进行运算的。考虑到孩子的理解能力，此处暂不做讲解。

## 1.1. 算术运算符

### 1.1.1. 算术运算符

对数据进行加减乘除等操作的运算符号被称为算术运算符。

运算符 | 含义 | 示例 | 运行结果
---|---|---|---
+ | 加法 | 1+2 | 3
- | 减法 | 2-1 | 1
* | 乘法 | 2*3 | 6
/ | 除法取整（取商） | 7/2 | 3 
% | 除法取余 （取模） | 7%2 | 1
++ | 自增（对自身增加 1 ） | ++2 | 3
-- | 自减 （对自身减 1 ） | --3 | 2


示例：

```java
/**
 * 注意，这里为了方便使用了中文拼音命名，但实际编码中不推荐使用中文拼音。
 */
public class SuanShuYunSuan {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;
        // 输出 9
        System.out.println(a + b);
        // 输出 5
        System.out.println(a - b);
        // 输出 14
        System.out.println(a * b);
        // 输出 3
        System.out.println(a / b);
        // 输出 1
        System.out.println(a % b);
    }
}
```

注意：

 *  `+` 和 `-` 也可以用于表示正数和负数。`+3` 表示正数3，`-2` 表示负数2。与数学中的含义相同。
 * `/` 除号两边如果都是整数，表示取商。但如果一侧包含小数，那么得到的结果就是小数。

```java
public class SuanShuYunSuan {
    public static void main(String[] args) {
        float a = 2.5f;
        float b = 10;
        // 输出 0.25
        System.out.println(a/b);
        // 输出 0.25
        System.out.println(2.5/10);
        // 输出 2.1
        System.out.println(10.5/5);
    }
}
```

### 1.1.2. ++ 和 -- 

使用 `++` 和 `--` 时需要注意，这两个符号放在数字前和数字后，结果是不一样的：

```java
/**
 * 注意，这里为了方便使用了中文拼音命名，但实际编码中不推荐使用中文拼音。
 */
public class SuanShuYunSuan {
    public static void main(String[] args) {
        int a1 = 7;
        // 先对 a 自增，然后把自增后的值给 b
        int b1 = ++a1;
        // 输出 a1=8，b=8
        System.out.println("a1=" + a1 + "，b=" + b1);

        int a2 = 7;
        // 先把 a 的值给 b, 然后再对 a 自增
        int b2 = a2++;
        // 输出a2=8，b2=7
        System.out.println("a2=" + a2 + "，b2=" + b2);

        int a3 = 7;
        // 先对 a 自减，然后把自减后的值给 b
        int b3 = --a3;
        // 输出 a3=6，b3=6
        System.out.println("a3=" + a3 + "，b3=" + b3);

        int a4 = 7;
        // 先把 a 的值给 b, 然后再对 a 自减
        int b4 = a4--;
        // 输出 a4=6，b4=7
        System.out.println("a4=" + a4 + "，b4=" + b4);
    }
}
```


## 1.2. 赋值运算符

赋值运算符就是把某个值或者表达式的运行结果赋给某个变量或常量。

运算符 | 含义 | 示例 | 结果
--- |--- |--- |---
`=` | 赋值 | a = 3; b = 3; | a = 3; b = 2;
`+=` | 加等于 | a = 3; b = 2; a += b; | a = 5; b = 2;
`-=` | 减等于 | a = 3; b = 2; a -= b; | a =1; b = 2;
`*=` | 乘等于 | a = 3; b = 2; a *= b; | a = 6; b = 2;
`/=` | 除等于 | a = 3; b = 2; a /= b; | a = 1; b = 2;
`%=` | 模等于 | a = 3; b = 2; a %= b; | a = 1; b = 2;

以 `+=` 为例：`a += b;` 等价于 `a = a + b`，先计算 `a+b` 的结果，然后把结果赋值给 `a`。



## 1.3. 比较运算符

用于对两个数值或者变量进行比较，比较结果是一个布尔值，即 true 或 false 。

运算符 | 含义 | 示例 | 结果
--- |--- |--- |---
`==` | 相等 | 4 == 3 | false
`!=` | 不相等 | 4 != 3 | true
`<` | 小于 | 3 < 4 | true
`>` | 大于 | 4 > 3 | true
`<=` | 小于或等于 | 3 <= 4 | true
`>=` | 大于或等于 | 4 >= 3 | true

注意：在使用 `==` 进行比较时，不要误写为 `=`。

## 1.4. 逻辑运算符

### 1.4.1. 逻辑运算符

逻辑运算符用于对布尔类型的数据进行操作，其结果还是一个布尔值。

> 编码过程中实际使用时，逻辑运算符的两侧也可能是一个表达式或者方法。

运算符 | 含义 | 示例 | 结果 | 备注
--- |--- |--- |---|---
`&` | 与运算（并且） |  `true & false` | false | 符号两边都为 true 时，结果才是 true
`|` | 或运算（或者）| `true | false` | true | 符号两边有一个 true ，结果就是 true 
`!` | 非运算（取反）| `!true` | false | 对 `!` 后的值取反就得到结果
`&&` | 短路与 | `true && false` | false | 符号两边都为 true 时，结果才是 true。含义与 `&` 相同。
`||` | 短路或 | `true || false` | true | 符号两边有一个 true ，结果就是 true 。含义与 `|` 想通。
`^` | 异或 | `true ^ false` | true | 符号两边不一样时才会返回 true 。

场景类比：

* `&`: 你和朋友去游乐场，你们想一起去玩，只有当你俩都有票时，才能一起去玩。
* `|`: 你和朋友在游乐场里口渴了，想买水喝，你俩只要有一人带了钱，就可以买到水。
* `!` : 这数学题你没有做对，那就是说你做错了。
* `^` : 磁铁有正极和负极，你把两块磁铁放在了一起，当仅靠的两头极性不同时两块磁铁才能吸附在一起。（同极相斥，异极相吸）
* `&&` ：你和朋友想一起去游乐场玩，但是你没有票，那么不论你朋友是否有票，你们都无法一起去游乐场玩耍了。（注意：这里的前提是每人只有一张票。）
* `||`: 你和朋友在游乐场里口渴了，想买水喝，你俩只要有一人带了钱，就可以买到水。

### 1.4.2. `&` 与 `&&` 、`|` 与 `||` 的区别：

对于 `&` 和 `|`, 不论左侧的值是什么，都会对右侧进行一次运算。

而对于 `&&` ，如果左侧已经是 `false`，则不会再对右侧内容进行运算；同理，对于 `||`, 如果左侧已经是 `true`，那么右侧也不需要进行运算了。
