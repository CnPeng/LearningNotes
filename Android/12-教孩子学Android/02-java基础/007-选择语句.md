# 1. 07-选择语句

## 1.1. if 选择语句

if 表示如果，如果怎么样，就怎么样。

if 语句有三种格式：if、if...else 、if ... else if... else  

### 1.1.1. if 

基本格式：

```java
if(条件表达式){
    // 满足条件时执行的代码块（当条件表达式的值为true时执行该代码块）
}
```

示例：

```java
public class If {
    public static void main(String[] args) {
        int score = 100;
        if (score >= 100){
            // 输出结果：这次考试成绩为：100，爸爸将带你去游乐场
            System.out.println("这次考试成绩为："+score +"，爸爸将带你去游乐场");
        }
    }
}
```


### 1.1.2. if...else

> else ：`/ els /` ( adj, 形容词) 其他的，别的。

`if... else` 表示：如果怎么样，否则怎么样。

基本格式：

```java
if(条件表达式){
    // 满足上述条件时，执行此处代码块
}else{
    // 如果不满足上述条件，执行此代码块
}
```

示例：

```java
public class If {
    public static void main(String[] args) {
        int score = 90;
        if (score >= 100) {
            // 输出结果：这次考试成绩为：100，爸爸将带你去游乐场
            System.out.println("这次考试成绩为：" + score + "，爸爸将带你去游乐场");
        } else {
            System.out.println("这次没考好，要加作业了");
        }
    }
}
```


### 1.1.3. if...else if ...else 

用于对多个条件进行判断，并进行不同的处理。

基本格式：

```java
if(条件表达式1){
    // 如果满足条件表达式1，执行这里的代码
}else if (条件表达式2){
    // 如果满足条件表达式2，执行这里的代码
}else if (条件表达式3){
    // 如果满足条件表达式3，执行这里的代码
}else{
    // 以上条件都不满足时，执行这里的代码
}
```

> `else if` 语句的数量可以根据实际情况动态的增加。

示例：老师要对本次考试成绩进行评级，大于等于 90 的评级为优，大于等于 80 的评级为良，大于等于 60 的评级为一般，其他的评级为不及格。对于这个需求，就可以使用 `if...else if ...else` 语句实现。

```java
public class If {
    public static void main(String[] args) {
        int score = 90;
        if (score >= 90) {
            System.out.println("你的评级为：优");
        } else if(score >= 80) {
            System.out.println("你的评级为：良");
        }else if (score >= 60) {
            System.out.println("你的评级为：一般");
        }else{
            System.out.println("你的评级为：不及格");
        }
    }
}
```


## 1.2. switch 选择语句 

### 1.2.1. switch 选择语句

switch 表示选择，挑选、开关。

switch 虽然也表示选择，但与 if 不同，switch 仅能对表达式的值就行判断。

基本格式：

```java
switch(需要判断的表达式的值){
    case 值1:
        // 当表达式的值为 值1 时，执行此处代码
        // break 表示打破、结束，不需要再执行后续判断。
        break;
    case 值2:
        // 当表达式的值为 值2 时，执行此处代码
        // break 表示打破、结束，不需要再执行后续判断。
        break;
    default:
        // 如果表达的值不是上面的任意一个，则执行此处的代码
        break;
}
```

> * switch : `/ swɪtʃ /` 选择、挑选、开关、切换。
> * case :`/ keɪs /` 具体情况，实例，案例
> * default :`/ dɪˈfɔːlt /` 默认的
> * break : `/ breɪk /` 打破、打断、破坏

示例：

```java
public class Switch {
    public static void main(String[] args) {
        // 基于 todayNum 的值，输出 “今天是周X” 的语句
        int todayNum = 1;
        switch (todayNum) {
            case 1:
                System.out.println("今天是周一");
                break;
            case 2:
                System.out.println("今天是周二");
                break;
            case 3:
                System.out.println("今天是周三");
                break;
            case 4:
                System.out.println("今天是周四");
                break;
            case 5:
                System.out.println("今天是周五");
                break;
            case 6:
                System.out.println("今天是周六");
                break;
            default:
                System.out.println("今天是周天");
                break;
        }
    }
}
```

### 1.2.2. case 穿透

正常情况下， 每一个 `case` 后面都要跟随一个 `break`。但某些特殊场景下，我们可以省略 `break`，让代码继续执行，这种就叫做 `case穿透`。

省略 `break` 时，仅会触发下方相邻的 `case` 中的代码。 

示例：

```java
public class Switch {
    public static void main(String[] args) {
        // 基于 todayNum 的值，输出 “今天是周X” 的语句
        int todayNum = 7;
        switch (todayNum) {
            case 7:
                // 这里省略了 break , 所以，当 todayNum 为 7 时会继续执行下方第一个case中的代码
            case 6:
                // 因为生面省略了 break, 所以当 todayNum 为 6 或 7 时，都会执行这句代码。
                System.out.println("今天是周末，不用上学");
                break;
            case 5:
                System.out.println("今天是周五");
                break;
            case 4:
                System.out.println("今天是周四");
                break;
            case 3:
                System.out.println("今天是周三");
                break;
            case 2:
                System.out.println("今天是周二");
                break;
            case 1:
                System.out.println("今天是周一");
                break;
            default:
                System.out.println("数值有误");
                break;
        }
    }
}
```
