## 1.2. java代码的基本结构

### 1.2.1. 常见数据

java 代码中常见的术语包括但不限于以下内容：

* 修饰符（public、private、procted）
* 包（package）、类（class）、接口（interface）
* 变量、常量
* 数据类型
* 方法、参数
* 数组、集合、枚举
* 注释（单行注释、多行注释(块注释)、文档注释）
* 标识符（类名、方法名、变量名、常量名等统称为标识符）

### 1.2.2. 代码基本结构

这里以一个类作为示例：

```java
修饰符 class 类名{
    修饰符 变量类型 变量名 = 变量值;

    修饰符 返回值类型 方法名(参数类型 参数名){
        具体的程序代码
    }
}
```
