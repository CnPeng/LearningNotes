# 1. 08-数组

一组相同类型数据的集合就是`数组`。

组成数组的数据被称为数组的`元素`。

数组中元素的数量被称为 `数组长度`。

元素在数组中的序号被称为`索引`，该序号从 0 开始计数，最后一个元素的索引为 `长度 - 1`。通过 `数组名[索引]` 的方式可以访问到指定索引处的元素值。


## 1.1. 数组

### 1.1.1. 数组的定义


#### 1.1.1.1. 方式1

先声明一个变量，然后构建一个数组，最后指定数组元素值。

```java
// 声明一个元素类型为 int 的数组变量，该变量名为 arr
int[] arr;
// 构建一个长度为 100 的数组，并赋值给 arr 变量
arr = new int[100];

// 指定 0 索引处的元素值为 3。
arr[0] = 3;
```

#### 1.1.1.2. 方式2

先声明一个指定长度的数组，然后给指定索引的元素赋值。

```java
// 定义一个元素类型为 int 的数组变量，该变量名称为 arr, 该数组的长度为 100 (即最大可存放 100 个元素)。元素的索引从 0 开始，最后一个元素的索引为 99
int[] arr = new int[100];

// 指定 0 索引处的元素值为 3。
arr[0] = 3;
```


#### 1.1.1.3. 方式3

直接构建数组并指定数组元素。

日常开发过程中，这种方式使用的比较多。

```java
// 直接构建数组并指定数组中的元素
int[] arr = new int[]{ 90, 99, 92, 98, 100};

// 上述方式可以简化为如下形式。
int[] arr = { 90, 99, 92, 98, 100 };
```

### 1.1.2. 数组的长度

数组的长度用 `length` 表示。通过 `数组名.length` 可以获取数组的长度。

```java
public class Arr {
    public static void main(String[] args) {
        // 声明一个长度为 4 的数组
        int[] intArr = new int[4];
        // 通过 数组名.length 获取数组的长度——即元素数量
        int arrLength = intArr.length;
        // 运行结果：数组的长度（元素数量）为：4
        System.out.println("数组的长度（元素数量）为：" + arrLength);
    }
}
```

### 1.1.3. 数组元素的默认值

我们声明了一个数组之后，如果没有指定具体的元素值，那么java会按照数据类型给每个元素一个默认值。

数据类型 | 默认值
--- | ---
byte、short、int、long | 0 
float、double | 0.0
char | 一个空字符。
boolean | false
引用数据类型 | null 


```java
public class Arr {
    public static void main(String[] args) {
        // 声明一个长度为 4 的数组，但并未指定数组中的元素值
        int[] intArr = new int[4];
        // 输出 int 类型的默认值 0
        System.out.println(intArr[0]);

        float[] floatArr = new float[4];
        // 输出 0.0
        System.out.println(floatArr[0]);

        double[] doubleArr = new double[4];
        // 输出 0.0
        System.out.println(doubleArr[0]);

        String[] strArr = new String[4];
        // 输出 null , String 是引用数据类型
        System.out.println(strArr[0]);

        char[] charArr = new char[4];
        // 输出 0 ，对应的是字符就是 ''
        System.out.println(charArr[0]);

        boolean[] booleanArr = new boolean[4];
        // 输出 false 
        System.out.println(booleanArr[0]);
    }
}
```

## 1.2. 多维数组

如果某个数组的元素还是数组，那么这种就被称为多维数组。

假设我们用一个大数组来表示民族小学五年级的全部学生，在大数组中用多个小数组表示具体班级的学生，那么， 我们就可以得到这样一个二维数组：

```java
public class Arr {
    public static void main(String[] args) {
        // 声明一个字符串类型的二维数组，3 表示 该二维数组又三个元素——即三个子数组（三个班级）。
        // 5 表示每个子数组中有 5 个元素——每个班级有 5 个学生
        String[][] grade5Students = new String[3][5];

        // 为二维数组的第1个元素（子数组）赋值。
        grade5Students[0] = new String[]{"张三", "李四", "王二麻子","赵大","钱二"};
        // 为二维数组的第2个元素（子数组）赋值。
        grade5Students[1] = new String[]{"李白", "杜甫", "贺知章","王维","杜牧"};
        // 为二维数组的第3个元素（子数组）赋值。
        grade5Students[2] = new String[]{"嬴政", "刘彻", "李世民","赵匡胤","朱元璋"};

        // 找出1班的第1个学生姓名。第一个[0]表示找出 grade5Students 数组的第一个元素（子数组），第二个[0] 表示找出子数组中的第一个元素。
        String name1 = grade5Students[0][0];
        // 运行输出：1班的第1个学生是：张三
        System.out.println("1班的第1个学生是：" + name1);

        // 找出2班的第3个学生姓名
        String name2 = grade5Students[1][2];
        // 运行输出：2班的第个3学生是：贺知章
        System.out.println("2班的第个3学生是：" + name2);

        // 找出3班的第4个学生姓名
        String name3 = grade5Students[2][3];
        // 运行输出：3班的第4个学生是：赵匡胤
        System.out.println("3班的第4个学生是：" + name3);
    }
}
```
