# 1. 沉浸式

## 1.1. 沉浸式实现

### 1.1.1. 定义主题

核心为下面代码中的 `FullScreen` 样式。

```xml
<resources>
    <!-- Base application theme. -->
    <style name="Base.Theme.JiNanPolice" parent="Theme.Material3.DayNight.NoActionBar">
        <!-- Customize your light theme here. -->
        <item name="colorPrimary">@color/primary</item>
        <!-- 修改 BottomNavigationView 不设置 itemTint 且 item 未选中时的图标渲染色 -->
        <item name="android:textColorSecondary">@color/selector_text_color_secondary</item>
        <!-- 全局修改页面背景色-->
        <item name="android:windowBackground">@color/background</item>


        <!--<item name="colorControlNormal">@color/unselected_color</item>-->
        <!--全局修改 checkbox 被选中时的填充色-->
        <item name="colorControlActivated">@color/primary</item>
    </style>

    <style name="Theme.JiNanPolice" parent="Base.Theme.JiNanPolice" />

    <!-- 全屏主题，用于实现沉浸式状态栏 -->
    <style name="FullScreen" parent="Theme.JiNanPolice">
        <!-- 其他属性 -->
        <item name="android:windowTranslucentStatus">true</item>
        <!-- 或者使用以下方式 -->
        <!-- <item name="android:statusBarColor">@android:color/transparent</item> -->
    </style>

</resources>
```

### 1.1.2. Activity 应用样式

通过 `android:theme="@style/FullScreen"` 指定样式。

```xml
   <activity
            android:name=".pages.main.MainActivity"
            android:theme="@style/FullScreen"
            android:exported="true">
            <intent-filter>
                <action android:name="${ENTRY_ACTION}" />

                <category android:name="${ENTRY_CATEGORY}" />
            </intent-filter>
        </activity>
```



### 1.1.3. Activity 页面布局文件设置

布局文件的根节点设置：`android:fitsSystemWindows="false"`

```xml
  <androidx.constraintlayout.widget.ConstraintLayout
        android:id="@+id/main"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:fitsSystemWindows="false"
        tools:context=".pages.main.MainActivity">

  </androidx.constraintlayout.widget.ConstraintLayout
```
