# 002-添加请求头

在 OkHttp 中，`header()`、`headers()` 和 `addHeader()` 是用于处理请求和响应头的方法，它们之间有以下区别：

* `header(String name, String value)`：

用于设置单个请求或响应头的值。
如果已存在相同名称的头，则**会覆盖原有的值**。

示例：

```java
Request request = new Request.Builder()
    .header("User-Agent", "OkHttp")
    .build();
```

* `headers(Headers headers)`：

通过传入一个 `Headers` 对象来替换所有的请求或响应头。

可以使用 `Headers.Builder` 来构建一个 `Headers` 对象并包含多个键值对。

示例：

```java
Headers headers = new Headers.Builder()
    .add("User-Agent", "OkHttp")
    .add("Content-Type", "application/json")
    .build();

Request request = new Request.Builder()
    .headers(headers)
    .build();
```

* `addHeader(String name, String value)`：

用于添加单个请求或响应头的值。
如果已存在相同名称的头，则**会追加新值而不是覆盖原有的值**。

示例：

```java
Request request = new Request.Builder()
    .addHeader("User-Agent", "OkHttp")
    .addHeader("Accept-Language", "en-US")
    .build();
```

总体来说，

`header()` 方法是用于设置单个头，如果已存在则**会覆盖**。
`headers()` 方法是用于一次性**替换所有**头。
`addHeader()` 方法则用于**添加新的头或追加已存在头的值**。选择使用哪种方法取决于你对请求或响应头的具体需求。
