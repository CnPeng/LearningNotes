# 001-整数转字符串


在Swift中将 `Int` 类型转换为 `String` 类型非常简单，可以直接通过初始化方法实现。以下是几种将 `Int` 转换为 `String` 的方法：

```swift
// 示例：有一个整数值
let intValue: Int = 42

// 方法1：使用初始化方法 String.init(value:ofType:)
let stringValue1 = String.init(value: intValue)

// 方法2：更简洁的写法，利用类型推断
let stringValue2 = "\(intValue)"

// 方法3：Swift 5.1及以上版本提供了String Interpolation API
let stringValue3 = String(describing: intValue)

// 输出验证
print(stringValue1) // 输出："42"
print(stringValue2) // 输出："42"
print(stringValue3) // 输出："42"

// 以上所有方法得到的结果都是相同的字符串 "42"
```

其中，方法 2 是最常见且最简洁的写法，通过反引号 `\(` 和 `)` 创建一个字符串插值表达式，编译器会自动处理类型转换。
