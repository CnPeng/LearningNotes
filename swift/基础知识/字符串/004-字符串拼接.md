# 1. 004-字符串拼接

在Swift中，拼接两个或多个字符串可以通过多种方式实现，以下是一些常见的方法：

## 1.1. 使用 `+` 运算符

   ```swift
   let str1 = "Hello,"
   let str2 = "World!"
   let combinedString = str1 + " " + str2
   print(combinedString) // 输出: Hello, World!
  ```

## 1.2. 使用字符串插值（String Interpolation）
   
   ```swift
   let firstName = "John"
   let lastName = "Doe"
   let fullName = "\(firstName) \(lastName)"
   print(fullName) // 输出: John Doe
   ```

## 1.3. 使用 `append` 方法

   ```swift
   var firstPart = "Hello"
   let secondPart = ", World!"
   firstPart.append(secondPart)
   print(firstPart) // 输出: Hello, World!
   ```

## 1.4. 使用 `joined(separator:)` 方法（适合拼接多个字符串，比如数组中的字符串元素）

   ```swift
   let parts = ["Hello", ",", "World!"]
   let message = parts.joined(separator: "")
   print(message) // 输出: Hello,World!
   ```

## 1.5. 多行文本连接

   如果你想在连接字符串的同时保留换行符，可以使用 `"\n"` 或者 `"\r\n"` 来表示换行，或者直接连接多行字符串字面量：

   ```swift
   let part1 = "Hello,\n"
   let part2 = "World!"
   let multilineString = part1 + part2
   print(multilineString)
   ```

   输出（带有换行）:
   
   ```
   Hello,
   World!
   ```

注意：使用 `+` 运算符或字符串插值时，Swift 会尽可能地重用现有内存空间来构建新的字符串，以减少内存分配次数，提高效率。
