## 1. 判断字符串不是nil且非空串

在Swift中，判断字符串（`String` 类型）非空且不为 `nil`，可以使用以下几种方式：

### 1.1. 使用条件组合：

```swift
   if let nonEmptyString = someOptionalString, !nonEmptyString.isEmpty {
       // 这里，nonEmptyString是非空且非空字符串
       // 执行相关逻辑...
   }
```

### 1.2. 使用可选链结合 `isEmpty`：

```swift
   if someOptionalString?.isEmpty == false {
       // 这里，someOptionalString不是nil且不是空字符串
       // 注意，若someOptionalString为nil，则表达式返回nil而非false，所以不会进入if块
   }
```

### 1.3. 使用Swift 5引入的 `compactMap` 和 `!= ""`：

```swift
   if let nonEmptyString = someOptionalString.compactMap({ $0 }) , nonEmptyString != "" {
       // 这里，nonEmptyString是非空且非空字符串
   }
```

### 1.4. 如果你想确保连续执行，在可选链的基础上也可以写成一行：

```swift
   if let nonEmptyString = someOptionalString?.trimmingCharacters(in: .whitespacesAndNewlines), !nonEmptyString.isEmpty {
       // 这里，不仅检查了非nil和非空，还自动移除了前后空白字符
   }
```

### 1.5. 对于非可选字符串（即已经确定不是nil的字符串变量），可以直接使用 `isEmpty` 属性：

```swift
   if myString.isEmpty == false {
       // 这里，myString不是空字符串
   }
```

简单来说，**第一种和第四种形式最为常用**，它们首先解包可选字符串，并在字符串非空时执行相关逻辑。同时，第四种形式还包含了处理空格的场景，确保字符串在去除前后空格后仍非空。

## 2. 判断字符串是nil或者是空串

在 Swift 中，字符串可以是可选类型 `String?` 或非可选类型 `String`。对于这两种情况，分别有不同的判断方法：

### 2.1. 对于可选字符串（String? 类型）

   判断字符串是否为 `nil` 或为空串，可以合并判断：

```swift
   let optionalString: String? = "..." // 可以为 nil 或一个字符串

   if optionalString == nil || (optionalString != nil && optionalString!.isEmpty) {
       print("字符串是 nil 或为空")
   } else {
       print("字符串非空")
   }
```

或者使用更简洁的 Optional 绑定和空合并运算符（`??`）配合 `isEmpty`：

```swift
   if optionalString == nil || (optionalString ?? "").isEmpty {
       print("字符串是 nil 或为空")
   } else {
       print("字符串非空")
   }
```

### 2.2. 对于非可选字符串（String 类型）

因为 Swift 的非可选类型 `String` 不能为 `nil`，所以只需要判断是否为空：

```swift
   let nonOptionalString: String = "..." // 必须初始化，不可能为 nil

   if nonOptionalString.isEmpty {
       print("字符串为空")
   } else {
       print("字符串非空")
   }
```

另外，如果想要一并处理空格问题（即一个字符串只包含空白字符，但在 Swift 中也是非空的），可以使用 `trimmingCharacters(in:)` 方法去除两端空白字符后再判断：

```swift
if optionalString == nil || ((optionalString ?? "").trimmingCharacters(in: .whitespacesAndNewlines)).isEmpty {
    print("字符串是 nil 或为空或仅包含空白字符")
} else {
    print("字符串非空且不全由空白字符组成")
}
``` 

以上代码适用于判断一个字符串是否为 `nil` 或者实际上是空的内容（包括无任何字符或仅包含空白字符）。
