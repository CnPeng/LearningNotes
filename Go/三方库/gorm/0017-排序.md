# 1. 0017-排序

## 1.1. convert


```go
db = db.Order("convert(name, SIGNED) asc, convert(name using gbk) asc") 
```

这行代码的作用是在查询结果排序时添加两个 `ORDER BY` 子句。

`convert()` 是 SQL 中的一个函数，用于在数据库层面对数据进行类型转换或编码转换。

`convert(name, SIGNED)`: 这个函数尝试将 `name` 字段（假设它是一个字符类型字段）转换为数值类型（`SIGNED` 通常指的是整数类型）。在排序时，SQL 尝试将字符串按照其能转换成的有效数字进行升序排列。如果 `name` 字段的内容不能被转换成有效的数字，则行为取决于具体的数据库引擎（有些数据库可能抛出错误，有些则可能忽略不能转换的行）。

`convert(name using gbk)`: 这个函数则是用来将 `name` 字段从当前字符集转换成 `GBK` 编码。在排序时，它首先将字符串按 `GBK` 编码格式转换，然后再进行升序排列。这对于处理多字节字符集时的排序非常重要，因为不同的字符集在排序规则上可能存在差异，转换编码可以确保在相同的字符编码下进行排序。

综合来看，这段代码试图先按照 `name` 字段能够转换为数字的结果进行升序排序，如果转换失败，则按照 `GBK` 编码格式下的字符串进行升序排序。实际应用中，这种排序逻辑可能并不常见，除非有特定的需求要这样处理数据。同时，这种转换依赖于所使用的数据库系统支持相应的 `convert` 函数和转换选项。
