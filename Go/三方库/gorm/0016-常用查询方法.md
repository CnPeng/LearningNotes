# 1. 常用查询方法
GORM 提供了多种查询方法，除了 `Scan`、`Find` 和 `Pluck` 之外，还有一些其他常用的方法，适用于不同的场景。以下是这些方法的简要说明：



## 1.1. Scan、Find和Pluck

在 GORM 中，`Scan`、`Find` 和 `Pluck` 是常用的数据查询方法，功能和使用场景有所不同：

### 1.1.1. Scan

- **功能**：将查询结果**映射到指定结构体或变量**中。
- **使用场景**：适用于自定义查询（如原生 SQL）或需要将结果映射到非模型结构体的情况。

**示例**：

```go
  var result struct {
      Name  string
      Email string
  }
  db.Raw("SELECT name, email FROM users WHERE id = ?", 1).Scan(&result)
```

### 1.1.2. Find

- **功能**：将查询结果**映射到模型结构体或结构体切片**中。
- **使用场景**：适用于查询多条记录并将结果映射到模型结构体。

**示例**：

```go
  var users []User
  db.Where("age > ?", 18).Find(&users)
```

### 1.1.3. Pluck

- **功能**：从数据库中提取**单列数据**并存储到切片中。
- **使用场景**：适用于只需要某一列数据的场景。

**示例**：

```go
  var names []string
  db.Model(&User{}).Pluck("name", &names)
```

### 1.1.4. 总结

- **Scan**：用于自定义查询或映射到非模型结构体（无法直接映射到数据库的自定义结构体）。
- **Find**：用于查询多条记录并映射到模型结构体（直接映射到数据库的结构体）。
- **Pluck**：用于提取单列数据到切片。

根据需求选择合适的方法。

## 1.2. 其他常用查询方法


### 1.2.1. **First**

- **功能**：查询符合条件的第一条记录。
- **使用场景**：当你只需要查询结果中的第一条记录时。

**示例**：

```go
  var user User
  db.Where("age > ?", 18).First(&user)
```
- **注意**：如果没有找到记录，会返回 `ErrRecordNotFound` 错误。

---

### 1.2.2. **Last**

- **功能**：查询符合条件的最后一条记录。
- **使用场景**：当你只需要查询结果中的最后一条记录时。

**示例**：

```go
  var user User
  db.Where("age > ?", 18).Last(&user)
```

- **注意**：如果没有找到记录，会返回 `ErrRecordNotFound` 错误。

---

### 1.2.3. **Take**

- **功能**：随机查询一条记录（不排序）。
- **使用场景**：当你只需要任意一条记录时。

**示例**：

```go
  var user User
  db.Take(&user)
```

---

### 1.2.4. **Count**

- **功能**：统计符合条件的记录数量。
- **使用场景**：当你只需要知道查询结果的数量时。

**示例**：

```go
  var count int64
  db.Model(&User{}).Where("age > ?", 18).Count(&count)
```

---

### 1.2.5. **Select**

- **功能**：指定查询的字段。
- **使用场景**：当你只需要查询部分字段时。

**示例**：

```go
  var users []User
  db.Select("name, age").Find(&users)
```

---

### 1.2.6. **Order**

- **功能**：指定查询结果的排序方式。
- **使用场景**：当你需要按特定字段排序时。

**示例**：

```go
  var users []User
  db.Order("age desc").Find(&users)
```

---

### 1.2.7. **Limit & Offset**

- **功能**：限制查询结果的数量和偏移量。
- **使用场景**：用于分页查询。

**示例**：

```go
  var users []User
  db.Limit(10).Offset(20).Find(&users) // 查询第 21-30 条记录
```

---

### 1.2.8. **Group & Having**

- **功能**：对查询结果进行分组和过滤。
- **使用场景**：用于分组统计。

**示例**：

```go
  var results []struct {
      Age   int
      Count int
  }
  db.Model(&User{}).Select("age, count(*) as count").Group("age").Having("count > ?", 10).Find(&results)
```

---

### 1.2.9. **Raw**

- **功能**：执行原生 SQL 查询。
- **使用场景**：当需要执行复杂的 SQL 查询时。

**示例**：

```go
  var users []User
  db.Raw("SELECT * FROM users WHERE age > ?", 18).Scan(&users)
```

---

### 1.2.10. **Exec**

- **功能**：执行原生 SQL 语句（通常用于更新、删除等操作）。
- **使用场景**：当需要执行非查询类 SQL 语句时。

**示例**：

```go
  db.Exec("UPDATE users SET name = ? WHERE id = ?", "John", 1)
```

---

### 1.2.11. **Joins**
- **功能**：用于表连接查询。
- **使用场景**：当需要从多个表中查询数据时。
- **示例**：
  ```go
  var results []struct {
      UserName  string
      OrderName string
  }
  db.Model(&User{}).Joins("left join orders on orders.user_id = users.id").Select("users.name as user_name, orders.name as order_name").Scan(&results)
  ```

---

### 1.2.12. **Preload**

- **功能**：预加载关联数据。
- **使用场景**：当需要查询模型及其关联数据时。

**示例**：

```go
  var user User
  db.Preload("Orders").First(&user, 1) // 查询用户及其订单
```

---

### 1.2.13. **Scopes**

- **功能**：定义可复用的查询逻辑。
- **使用场景**：当需要将常用的查询条件封装为方法时。

**示例**：

```go
  func ActiveUsers(db *gorm.DB) *gorm.DB {
      return db.Where("active = ?", true)
  }

  var users []User
  db.Scopes(ActiveUsers).Find(&users)
```

---

## 1.3. 总结

GORM 提供了丰富的查询方法，适用于不同的场景：

- **查询单条记录**：`First`、`Last`、`Take`。
- **查询多条记录**：`Find`。
- **查询特定字段**：`Select`、`Pluck`。
- **统计**：`Count`。
- **分页**：`Limit`、`Offset`。
- **复杂查询**：`Raw`、`Joins`、`Group`、`Having`。
- **关联查询**：`Preload`。
- **复用查询逻辑**：`Scopes`。
