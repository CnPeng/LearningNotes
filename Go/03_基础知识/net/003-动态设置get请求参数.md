# 003-动态设置get请求参数

GET 请求动态设置参数

在 golang 中，可以使用 `http.Parameter` 对象来动态设置HTTP请求参数。

`http.Parameter`对象是一个 `map[string][]string` 类型的结构体，其中 `map[string][]string` 表示一个键值对的集合，其中每个键表示一个 HTTP 请求参数的名称，每个值表示该请求参数的值。

以下是一个使用 `http.Parameter` 对象动态设置 HTTP 请求参数的示例：


```go
package main

import (
    "fmt"
    "net/http"
)

func main() {
    // 创建一个HTTP请求
    req, err := http.NewRequest("GET", "http://example.com/", nil)
    if err != nil {
        panic(err)
    }

    // 设置HTTP请求参数
    param := map[string][]string{
        "id": []string{"12345"},
        "name": []string{"Alice"},
    }
    req.URL.RawQuery = url.Values(param).Encode()

    // 发送HTTP请求
    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }

    fmt.Println("Status code:", resp.StatusCode)
    fmt.Println("Body:", string(resp.Body))
}
```

上述代码中，

我们使用 `http.NewRequest` 函数创建了一个 GET 请求，并使用 `url.Values` 函数将 `param` 参数转换为 `url.Values` 类型的值。

然后我们使用 `req.URL.RawQuery` 将 `url.Values` 类型的值设置为请求参数，并使用 `http.DefaultClient.Do` 函数发送了 HTTP 请求。最后，我们将响应的状态码和响应体输出到控制台上。

需要注意的是，在使用 `http.Parameter` 对象动态设置 HTTP 请求参数时，需要注意请求参数的名称和值的正确性和完整性。同时，在使用 `url.Values` 函数将 param 参数转换为 `url.Values` 类型的值时，需要注意参数的名称和值的正确性和完整性。
