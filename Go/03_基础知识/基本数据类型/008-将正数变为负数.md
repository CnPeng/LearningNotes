# 008-将正数变为负数

在Go语言中，要将一个正数转换为负数，最直接的方法就是简单地给这个数前面加上负号 `-`。这是一种算术运算，可以直接应用于整数、浮点数等各种数值类型。例如：

```go
package main

import "fmt"

func main() {
    // 假设有一个正数
    positiveNumber := 10

    // 转换为负数
    negativeNumber := -positiveNumber

    fmt.Println("Original positive number:", positiveNumber)
    fmt.Println("Converted negative number:", negativeNumber)
}
```

在这个例子中，`positiveNumber`变量存储了一个正数10，通过在它前面加上负号 `-`，我们得到了它的负数版本 `-10`，并将其赋值给了`negativeNumber`变量。这种方法简洁明了，适用于绝大多数需要转换正负数的场景。
